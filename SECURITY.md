# Security policy

TaskForge is an educational application and is not intended for production
deployment. Its sample accounts, local SQLite databases, and example secrets
exist only to support the tutorial exercises.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's private
security-advisory flow for this repository instead:

1. Open the repository's **Security** tab.
2. Choose **Advisories** and **Report a vulnerability**.
3. Include the affected track, reproduction steps, and expected impact.

Do not include live credentials, tokens, or personal data in a report.

## Supported version

Only the current `main` branch and the `course-v1/starter` checkpoint receive
security corrections. Tutorial exercise branches may intentionally contain
incomplete implementations and should never be deployed.
